# Medifix Hospital Limited Website

A modern, responsive healthcare website developed for Medifix Hospital Limited.

The website is designed to provide patients with clear information about the hospital, available services, contact details, and an easy way to request appointments online.

## Features

- Responsive hospital website for desktop, tablet, and mobile
- Hospital information and services
- About section
- Contact information and location
- Google Maps integration
- Appointment request form
- Appointment management for authorized hospital staff
- Email notifications for new appointment requests
- WhatsApp contact integration
- Staff authentication and role-based access
- Secure database storage using Supabase
- Modern healthcare-focused user interface

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- Supabase
- Resend
- Git & GitHub
